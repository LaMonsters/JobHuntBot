OfferTrack · 秋招工作台（空白分享版）
================================================

一、这是什么

这是一份已经做过隐私清理的秋招投递工作台，包含投递看板、日程、复盘、简历管理和岗位采集插件。
首次启动时为 0 条投递记录、0 份简历，不包含任何人的投递信息、简历或浏览器痕迹。已附带分享者提供的飞书岗位表链接，可在“岗位信息库”中查看。

二、运行要求

1. Windows 10/11，推荐 Edge 或 Chrome。
2. 安装 Node.js 18 或更高版本。可在命令提示符输入 node --version 检查。
3. 工作台不需要数据库、云服务、账号或 API Key。

三、快速开始

1. 先把整个压缩包解压到普通文件夹，不要在压缩包预览窗口里直接运行。
2. 双击根目录的“启动秋招工作台.bat”。
3. 浏览器会打开 http://localhost:8420/dashboard.html。
4. 点击“添加岗位”开始记录。只有真正完成网申后，才把阶段改为“已投递”并填写投递日期。

如果只想临时看界面，也可直接双击 dashboard\dashboard.html。但要上传和管理 PDF 简历，请使用 localhost 启动方式。两种打开方式的浏览器数据空间不同，建议始终固定使用 localhost。

四、主要功能

- 总览：投递数量、进行中流程、七天内安排、Offer 数量、今日待办和日历。
- 我的投递：用看板或表格管理岗位阶段，支持编辑、删除、标签、收藏和匹配度。
- 添加岗位：记录公司、岗位、城市、链接、截止日期、JD、备注、简历版本与后续安排。
- 简历管理：上传、查看、下载、重命名和删除 PDF 简历。
- 投递复盘：按周查看投递趋势、阶段分布、推进率和长时间未进展的岗位。
- 岗位信息库：内嵌分享者提供的飞书校招岗位表，支持使用表格内的搜索、筛选与视图切换。也可点击“在飞书打开”查看原表。表格需要联网，访问权限与登录要求由飞书管理；若提示无权限，请联系表格所有者申请访问。在线表格不会自动导入到“我的投递”。

五、岗位采集插件（可选）

1. Edge 输入 edge://extensions，Chrome 输入 chrome://extensions。
2. 打开“开发人员模式”。
3. 选择“加载已解压的扩展程序”，选中 offertrack-extension 文件夹。
4. 在企业官网或招聘网站的单个岗位详情页打开插件，核对识别结果后填入工作台。

详细说明见 offertrack-extension\使用说明.md。插件只在点击时读取当前页面，不会填写或提交网申。

六、数据在哪里

- 新版岗位记录保存在当前浏览器的本地存储中，键名为 jobhuntbot.offertrack.v1。
- PDF 简历副本保存在 dashboard\.resume-data\ 中，第一次启动后按需自动创建。
- dashboard 目录中的 CSV 文件只有表头，供兼容旧版看板使用。
- 数据不会上传到开发者的服务器。“岗位信息库”和浏览器采集插件在访问第三方网站时会需要联网。

七、备份与迁移

- 定期点击“导出备份”保存 JSON；恢复时使用“导入备份”。导入会替换当前岗位记录，操作前先导出。
- JSON 备份不包含 PDF。迁移简历时，请同时备份 dashboard\.resume-data\ 文件夹。
- 不要把已填入自己记录、备份或简历的工作文件夹直接发给别人；分享时请使用这份原始空白压缩包。

八、可选：Windows 登录后自动启动

双击“设置登录后自动启动.bat”。如果之后移动了整个文件夹，需在新位置重新运行一次。
如需取消，按 Win + R，输入 shell:startup，删除 OfferTrack.lnk。

九、常见问题

- 提示找不到 Node.js：安装后重新打开压缩包所在文件夹，再双击启动脚本。
- 页面打不开：检查 8420 端口是否被占用；日志在 %LOCALAPPDATA%\OfferTrack\ 中。
- 换浏览器或换打开地址后看不到记录：数据空间不同，请回到原浏览器和 http://localhost:8420，或导入之前导出的 JSON 备份。
- 程序关闭：后台服务会在注销或关机时结束，下次双击启动脚本即可。
