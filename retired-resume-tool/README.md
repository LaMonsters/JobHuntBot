# 秋招 · 简历管理

参考所提供的页面布局，为当前项目新增的本地简历管理工具。支持上传和管理多份 PDF 简历，不包含简历优化或制作功能，不会修改 Offerbiu 线上网站。

## 打开

双击本目录的 **打开简历管理.cmd**，会启动工具并打开浏览器。

启动后也可以访问 <http://127.0.0.1:8765>。关闭浏览器不删除简历；电脑重启后，重新双击启动文件即可。

启动时的窗口需要保持打开；关闭它或按 Ctrl+C 会停止服务，已保存的简历仍会保留。重复双击会重新打开现有页面。

运行需要 Python 3.10 或更新版本，无需安装第三方依赖。当前电脑已有 Python 3.12。

## 使用

- 点击「上传新简历」或「选择文件」，按住 Ctrl / Shift 选择多份 PDF；也可以将文件拖到上传区域。
- 单份最大 20 MB，不设置简历数量上限。总量取决于磁盘剩余空间。
- 内容不同的同名文件分别保存，不会覆盖。内容完全相同的文件会提示重复并跳过。
- 每个卡片提供查看、下载、重命名和删除。重命名修改卡片名称，下载保留原文件名。
- 查看会在新标签页打开 PDF，具体预览方式取决于浏览器。浏览器不支持预览时可下载查看。
- 删除只影响简历库中的副本，不影响你最初上传的原文件。删除前有确认提示。
- 批量上传会逐份给出结果，失败的文件可以再次选择上传。文件扩展名和 PDF 文件头都会被检查；工具不解析或评价简历内容。

## 文件保存与备份

上传的简历持久保存在本项目中：

```text
data/
  resumes.sqlite3   # 简历名称、原文件名、日期等索引
  files/            # PDF 文件；内部采用独立编号，防止同名覆盖
```

文件和索引均在本机磁盘，不依赖浏览器缓存，也不会发送到第三方网站。迁移或备份时，先结束本工具的 Python 进程，再复制整个 `data` 文件夹；文件和索引需要一起保留。`data/` 已加入 `.gitignore`。

仅允许本机访问（绑定 `127.0.0.1`）。不提供账号、跨设备同步或公网部署功能。

## 开发

```powershell
python resume_manager.py
python -m unittest discover -s tests -v
```

可以通过 `--port 8766` 改端口，通过 `--data-dir 路径` 指定其他数据目录。默认启动文件固定使用 8765。

入口为 `resume_manager.py`，界面在 `web/`，接口以 `/api/resumes` 为前缀。测试使用隔离的临时目录，不读写真实简历。
