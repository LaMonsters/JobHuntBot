## 实现依据

- [Chrome scripting 官方文档](https://developer.chrome.com/docs/extensions/reference/api/scripting)：使用 Manifest V3、activeTab 和 scripting，在用户选择的当前标签页执行提取函数。
- [Chrome tabs 官方文档](https://developer.chrome.com/docs/extensions/reference/api/tabs)：打开配置的本地工作台。
- 规则提取在浏览器本地运行，无 API 费用。结构化信息、中文字段标签和用户选中内容依次作为来源。网页上的报名截止时间与个人面试安排分别保存。
