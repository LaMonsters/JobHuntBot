        使用说明

        简单记录，安心跟进。

        1. 记录进展
        点击“新增投递”保存岗位信息，默认加入待投递。完成网申后展开“投递进度与安排”，更新阶段和投递日期。列表右侧的铅笔可编辑，垃圾桶可删除，删除后可短暂撤销。点击统计卡片或筛选项可快速查找记录。

        2. 查看安排
        每条记录可保存一项最近安排，日期未确定时可只写名称。七天范围为今天 00:00 至第七天 23:59，已结束、已撤回的流程不计入安排。点选日历日期可筛选，再点一次显示整周。

        3. 保存与备份
        数据自动保存在当前浏览器。请使用固定浏览器和打开方式；换浏览器、移动文件、改用 localhost 或清理浏览器数据后，可能需要导入备份。使用“导出备份”保存 JSON 文件，在“导入备份”中恢复。导入前会让你确认替换。

        4. 示例与原有项目
        首次打开会显示 8 条虚构示例，可一键清空。基础版独立使用浏览器存储；原有 CSV 数据和旧版看板保留在项目中，可通过本地启动脚本访问 dashboard-legacy.html。
