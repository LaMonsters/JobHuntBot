# Windows 自动启动验证

日期：2026-09-04。

当前 Windows 用户的“启动”文件夹已安装 `OfferTrack.lnk`。已读取核对快捷方式：使用 Windows PowerShell 隐藏窗口调用 `start-dashboard-background.ps1`，Node 路径为本机实际安装位置。

验证结果：

- 直接执行后台启动脚本，可识别已运行的 OfferTrack，不重复创建服务。
- 当前 `http://localhost:8420/dashboard.html` 返回 HTTP 200。
- 使用独立临时目录和端口 18420 验证冷启动：真实 Node 服务成功运行，启动脚本退出后仍可访问，重复运行复用原进程，无服务器错误。四项检查通过；测试服务 20 秒后自行退出。
- 服务仍只监听本机地址；未修改岗位记录、CSV 内容或浏览器存储。

验证边界：工具自动审批拦截了重启当前服务和再次触发启动快捷方式的验证，未执行这些操作。采用独立临时服务完成了后台启动流程测试。没有实际注销或重启 Windows；登录后的自动触发尚未实测。

运行日志在 `%LOCALAPPDATA%\OfferTrack`。取消自动启动可运行 `shell:startup`，删除 `OfferTrack.lnk`。
