验证日期：2026-09-05。修改前先提交 git 检查点（7bbebbd），全部测试在隔离浏览器会话完成。

## 修复内容（offertrack-extension）

- `extractor.js`：网页标题切分支持两侧无空格的 `-`（国聘标题为“岗位-公司-平台”格式），且数字区间（如 2026-2027）不被误切；纯站名/年份片段不会当作岗位名称。
- `extractor.js`：“职位介绍”“职位职责”加入 JD 信号词；正文完全无关键词时降级采用 `.job-detail` 等岗位区块并在警告中说明；JD 统一裁剪——从第一条信号行开始，遇到“竞争力分析/工作地点/单位信息”等小节标题即截断，并过滤“国聘平台免费提供……/谨防上当受骗/热线电话/更新于”等平台杂音行。
- `extractor.js`：岗位名称选择器补充 `.title-section .title` 兜底（国聘硬刷新后 `document.title` 可能只剩“国聘”）。
- `popup.html` / `popup.js` / `popup.css`：岗位名称与 JD 均为空时的校验报错，现在同时显示在“填入工作台”按钮正下方（此前只在弹窗顶部状态行，弹窗滚到底部时看不到，表现为“点了没反应”）。

## 发现的既有问题（与本次插件改动无关）

用 git stash 基线（旧版提取器）对照运行，失败点完全相同，证明以下问题在本次改动前已存在：

1. 工作台现默认打开看板视图（`workspace.js` `view = 'board'`），表格视图被隐藏，`verify-job-capture.js` / `verify-job-file-mode.js` 假定默认表格视图，需先切换或预置视图偏好。
2. 刷新后工作台默认落在“总览”页而非“投递记录”页，`#search` 等表格元素不可见。
3. 当前 Edge 中，编辑“待投递”记录时“当前阶段”下拉框位于折叠的“投递进度与安排”内（Playwright 判定不可见，`selectOption` 超时）。人工操作可点开折叠区，不影响使用，但脚本需要先展开。

以上属于工作台/QA 脚本与新版 Edge 行为的漂移，待后续单独处理。
