# 标签页复用验证

版本：1.0.1；日期：2026-09-04。

在隔离 Edge 浏览器中实际加载扩展，用真实 Chrome tabs/windows API 验证。`node qa/verify-tab-reuse.cjs` 的 14 项检查通过。

- 没有打开工作台时创建一个标签页，并正确填入岗位。
- 后续导入复用同一标签页 ID，不增加标签页数量，不重新加载页面，保留原来的查询参数及页面状态。
- 激活已有标签页；工作台在其他窗口时复用该标签页并聚焦对应窗口。
- 未保存表单先询问是否替换；取消保留字段，确认后才填入新岗位。
- 重复导入同一采集结果也正常触发，不自动新增投递记录。

匹配以配置的工作台完整地址为准，忽略查询参数和 fragment；写入时保留已有查询参数，只更新 fragment。不同来源（localhost、127.0.0.1、file）及不同路径的工作台不会混用，以免跨数据空间。

增加 `tabs` 权限，用于查找尚未获得 activeTab 临时权限的已有工作台标签页。无新增网站内容访问权限。参考 [Chrome Tabs API 权限与更新接口](https://developer.chrome.com/docs/extensions/reference/api/tabs) 和 [Windows API](https://developer.chrome.com/docs/extensions/reference/api/windows)。
