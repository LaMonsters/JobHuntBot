# 秋招总工作台：五项功能验收范围

目标入口始终是原来的 `http://localhost:8420/dashboard.html`。参考 Offerbiu 的总览、我的投递、添加岗位、简历管理、投递复盘；不增加简历优化、AI 生成或会员等其他模块。

1. **总览**：保留已有统计与近期安排，增加岗位总量、本周投递趋势、三天内截止、今日待办及可切换月份的投递台历；所有结果由真实的本地记录计算，空列表有明确状态。
2. **我的投递**：同一份数据可切换阶段卡片看板与表格；搜索公司、岗位、城市、标签、JD、备注和绑定简历；收藏、已记录匹配度、三天内截止、高匹配度、已绑定简历、未安排时间快捷筛选；状态更新、编辑、删除和导出可用。
3. **添加岗位**：侧边栏有直接入口；复用原表单与插件导入，保存公司、岗位、城市、类型、链接、截止日、JD、备注和绑定 PDF；可记录投递日期、笔面安排、跟进日期、下一步行动与个人复盘。
4. **简历管理**：保留已经集成的批量 PDF 上传、查看、下载、命名、删除与岗位绑定；原记录、简历文件及本地启动方式继续可用。
5. **投递复盘**：按周展示投递量、笔面安排、推进率、日投递分布、阶段分布、临近截止、长期停滞、近期安排、行动建议和已保存的个人复盘；可跳回对应岗位编辑。

共同要求：重要修改前保存本地 Git 检查点；不推送远程；保留旧数据和旧备份兼容性；检查跨页面联动、刷新后保存、导出、空状态、桌面及手机布局。测试使用隔离数据，不改动用户真实记录。

匹配度为可选的手动记录，未填写时不算已匹配；不伪造 AI 分析结果。看板保留原有「筛选中」「已撤回」阶段，避免丢失旧记录。
