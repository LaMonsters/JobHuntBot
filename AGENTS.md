# Local project workflow

- Before each important change, save a local Git checkpoint so the user can undo it.
- Do not push code, commits, or user data to a remote service unless the user explicitly requests it.
- Extend the existing `dashboard/dashboard.html` workbench and its server on port 8420. Do not create a separate dashboard for a feature.
- Keep personal resumes, browser data, and populated application records out of Git checkpoints.
